# SIN-T Мой пет проект. Пишу свой синтезатор в формате CLAP на C++ без фреймворков.

Что мне предстоит доработать в уже написаных модулях:

1) env - возможность создавать нелиннейные зависимости выходного значения от времени
2) env - в огибающей сейчас есть только три из четырёх стадий (A->S->R). Нужно добавить Decay, как минимум.
3) env - я думаю над тем, чтобы envelope, и в будущем модуль modulation наследовались от одного класса - предка. Так как env - это, по сути, та же самая модуляция. Корневая логика у них должна быть одинаковая.
4) generator - нужно сделать логику, которая будет сменять старые голоса новыми, когда при всех занятых голосах нажимается новая клавиша. Например, при maxVoice = 8, нажата 8 + 1 клавиша.
